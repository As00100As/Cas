# کدستان — پروژه‌ی آموزش برنامه‌نویسی و IT

## اجرا
`index.html` را در مرورگر باز کن (بدون نصب). برای اجرای پایتون (Pyodide) و SQL و پلی‌گراندهایی که کتابخانه‌ی CDN دارند اینترنت لازم است.
اگر خواستی با سرور محلی اجرا کنی: `python3 -m http.server 8000`

## ساختار
```
index.html            صفحه‌ی اصلی (فقط اسکلت و فراخوانی فایل‌ها)
css/app.css           ظاهر
js/core.js            داده‌ی مشترک و وصله‌های سازگاری
js/app.js             منطق برنامه (نمایش درس، آزمون، پیشرفت، اجرای کد)
data/courses/*.js     هر دوره یک فایل (۲۵ دوره‌ی قبلی + دوره‌های جدید)
data/manifest.json    فهرست و ترتیب دوره‌ها
tools/syllabus/       سرفصل ۲۰۰ درسی هر دوره‌ی جدید (۴ سطح × ۵۰)
tools/lessons/<دوره>/ درس‌های نوشته‌شده (فایل‌های پایتون)
tools/build.py        ساخت data/courses و index.html از سرفصل + درس‌ها
tools/test_py.py      اجرای واقعی همه‌ی کدهای پایتون درس‌ها
docs/                 یادداشت‌های پروژه
```

## افزودن درس
1. در `tools/lessons/<دوره>/` فایل جدید بساز؛ هر درس با `add(سطح, شماره‌ی_سرفصل, متن, تمرین, py=کد)`.
2. `python3 tools/build.py` و بعد `python3 tools/test_py.py <دوره>`.
عنوان درس از سرفصل می‌آید. هر سطح می‌تواند `QUIZ` و `CHALLENGE` هم داشته باشد (نمونه: `tools/lessons/pyzero/l1_b.py`).

## دوره‌های جدید
پایتون از صفر (pyzero) • هوش مصنوعی (ai) • شبکه (network) • IT (it) • سخت‌افزار (hardware) — هرکدام ۲۰۰ درس؛ وضعیت در `docs/progress.md`.
